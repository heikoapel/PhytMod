How to use PhytMod

Menu File
Open Opens a previously saved PhytMod file, i.e. a saved Model definition and runs the model
Save Save the current model definition
Save As Save the current model definition to file
Import Import measured data of the visible infection from a space/tab delimited ASCII file for display in the visible infection graphic. It assumes data entries in columns without column headers, with the first column indicating the day of measurement and the second the data of the normalized visible infection (I + D). If more than two columns are present in the file, the rest are neglected.
Export Exports the data in the data table sheet as a space delimited ASCII file for use in other programs, e.g. Excel, Mathematica, ...
Exit Exits PhytMod

Menu Model
Run new Runs the model and redraws both graphic windows and fills the model data table sheet with the calculated data.
Run same Runs the model and draws a temporary graph over the visible graph window, i.e. all stages or visible infection. These graphs will vanish as soon as the window is resized, moved, etc. Also, the model data table sheet is not filled with data of "same" runs. Use 'Run new' instead.

Model definition
 
latent period l specify the length of the latent period in days; double value
infect. period i specifiy the length of the infectious period in days; double value
infection rate R specifiy the infection rate; double value
initial infection specify the initial infection; double value, should be realistically low, i.e. < 0.05
runtime specify the length of the model run (tmax) in days; integer value
stepsize specify the stepsize of the calculation in days; restricted to 0.1, 0.2, 0.5 and 1.0
Standard Model
Button		 selects the standard model (see documentation) for model run. With this option the fungicide applications are not available.
Phytophthora model
Button		 selects the Phytophthtora model (see documentation) for model run. With this option the lesion grwoth, sporulation intensity and fungicide applications are available.
lesion growth W specify the linear lesion growth parameter; double value, restricted to <= 1
sporulation intensity specify the sporulation intensity of the aporulation function (see documentation); double value
Fungicide application defines the fungicide application type
Selection "no'" no rungicide application
Selection "protective" selects the protective fungicide Mancozeb for application
Selection "curative" selects the curative and protective fungicide mix Mancozeb + Metalaxyl for application
application days defines the fungicide aplication days 
interval selection selects a regurlarly application scheme
interval input field defined the interval length in days; integer value
start defines the starting days of the interval application scheme
user selection select user defined application days
user input field defines the application days, integer values, comma seperated
show imported data selects whether imported data of the visible infection are shown in the visible infection graph or not
